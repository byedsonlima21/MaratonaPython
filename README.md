# 🐍 Maratona Python

Boas-vindas ao meu repositório de estudos! 👋

Este espaço foi criado para ser o meu "diário de bordo" na jornada de aprendizado da linguagem Python. Aqui, eu guardo todas as atividades e exercícios que resolvo acompanhando o **Curso em Vídeo** NO YouTube, ministrado pelo professor Gustavo Guanabara.

O objetivo principal do projeto **MaratonaPython** é registrar o meu progresso passo a passo, acompanhar minha evolução a cada linha de código escrita e construir uma base sólida na programação. Se você também está aprendendo Python, sinta-se à vontade para explorar os códigos, comparar soluções e se inspirar!

## 📂 Como os estudos estão organizados?

O repositório está estruturado de forma lógica, seguindo a trilha de aprendizado do curso. Atualmente, os tópicos documentados incluem:

* **01 - Fundamentos:** Os primeiros passos, conceitos básicos e as operações iniciais.

* **02 - Condições:** Trabalhando com a lógica fundamental do `if` e `else`.

* **03 - Condições Aninhadas:** Aprofundando nas tomadas de decisão e fluxos mais complexos.

* **04 - Estruturas de Repetições - For:** Criando laços de repetição com limites definidos.

* **05 - Estruturas de Repetições - While:** Dominando loops baseados em validações e condições lógicas.

* **06 - Estruturas de Dados - Tuplas:** O início da exploração em variáveis compostas.

* **07 - Estruturas de Dados - Listas** Início da manipulação de listas

*(Novos módulos e desafios serão adicionados conforme eu avançar nas aulas!)*
